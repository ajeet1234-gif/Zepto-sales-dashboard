# 📊 Zepto Sales Dashboard | Microsoft Excel

## 📌 Project Overview

This project is an interactive *Zepto Sales Dashboard* developed in *Microsoft Excel* to analyze sales performance using visual reports and KPIs. The dashboard provides insights into sales, item visibility, outlet performance, product categories, outlet sizes, city types, and customer ratings.

---

## 🎯 Objective

The objective of this project is to transform raw sales data into an interactive dashboard that helps understand business performance and supports better business decision-making.

## 📊 Dashboard Analysis

The dashboard includes the following visualizations:

•⁠  ⁠Outlet Establishment vs Total Sales (Column Chart)
•⁠  ⁠Fat Content Analysis (Doughnut Chart)
•⁠  ⁠Item vs Total Sales (Horizontal Bar Chart)
•⁠  ⁠Outlet Size Analysis (Column Chart)
•⁠  ⁠City Type vs Sales (Pie Chart)
•⁠  ⁠Outlet Location Type vs Sales (Doughnut Chart)
•⁠  ⁠Item vs Average Item Visibility (Line Chart)
